# 🍼 Mothers Milk Bank Management System

A Full Stack Web Application developed to manage the complete workflow of a Mother's Milk Bank, including donor registration, milk donation, inventory management, milk requests, payments, and administration.

## 📌 Features

- User Registration & Login
- Milk Donation Management
- Milk Request Management
- Donor Information
- Inventory Management
- Payment Management
- Contact Us Module
- Admin Dashboard
- User Dashboard
- Authentication & Authorization

## 🛠️ Technology Stack

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST APIs
- Maven

### Database
- MySQL

## 🚀 How to Run

### Backend

```bash
cd backend
mvn spring-boot:run
```

### Frontend

```bash
cd frontend/my-app
npm install
npm start
```
